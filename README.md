# SAT-AGRO AMÉRICAS — Next.js Premium v0.2

Base de producción, no maqueta HTML estática.

## Stack
- Next.js 15 / React 19 / TypeScript
- App Router
- Diseño responsive modular
- Preparado para incorporar MapLibre, ECharts, APIs server-side, autenticación y PDF

## Rutas
`/` `/proyecto` `/que-hacemos` `/regiones` `/demo` `/plataforma` `/datos` `/institucional` `/planes` `/contacto`

## Ejecutar
```bash
npm install
npm run dev
```

El INDEX fue deliberadamente simplificado: impacto visual, mensaje, proyecto, capacidades, demo y puertas a páginas internas. El dashboard completo pertenece a `/plataforma`.
